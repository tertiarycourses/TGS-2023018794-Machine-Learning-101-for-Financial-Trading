Prompt Library

Machine Learning 101 for Financial Trading · Let AI write the code. Every lab works without coding in the Trading Simulator; use these prompts when you want to see, run or customise the code behind a lab.

How to use
  1. Click 'Open in Claude' or 'Open in ChatGPT': the prompt is filled in for you. Press Enter.
  2. Colab prompts: open Google Colab (colab.research.google.com) > New notebook, paste the code the AI wrote into a cell and press Run. Nothing to install.
  3. Strategy Builder prompts: paste the code into the simulator's Strategy Builder, press Validate, then Save - it then appears in Backtest, Diagnostics and Paper Trading.
  4. If the code stops with an error, paste the error back into the same chat and ask the AI to fix it.
  5. Never paste API keys into an AI chat. Paper trading only - nothing here is investment advice.
